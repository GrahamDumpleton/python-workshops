# Welcome to the Python workshops

These are guided, hands-on workshops that teach the Python programming
language. They are written for people who have never written a program
before. You do not need to know anything about programming to start.

Each workshop is a set of short pages. The pages appear in the panel on
the right of the screen. Each page explains one idea, and then asks you
to do something with it. Some steps are done by clicking a box on the
page. Other steps ask you to type code yourself. The workshop checks
your work as you go, and tells you what to look at if something is not
right.

The workshop browser lists the workshops in the order to take them.
Start with the first one, **How these workshops work**. It explains
how to use the pages, the notebook and the checks. At the end of each
workshop, the Finish dialog offers you the next one.

## Where your work is kept

This JupyterLab runs completely inside your web browser. There is no
server and you do not need an account. Python itself runs in this
browser tab. Your work is saved in your browser's own storage on this
computer. It is still there if you reload the page, or if you come back
on another day. But it is only in this browser on this computer, and if
you clear the browser's data for this site, your work is deleted. When
you have finished, close the tab. There is nothing to shut down.

When you reload the page, Python starts again, and forgets the values
your earlier code created. The workshop then asks whether to restart
the workshop or continue. The first workshop explains what each choice
does.

## The later workshops

The workshops here cover the first four parts of the course. The last
two parts teach you to write programs in files and run them in a
terminal, and they need a real computer rather than a browser. The
last workshop here explains how to continue on GitHub Codespaces, on
mybinder.org, or on your own computer.

## Your progress

While you work through a workshop, your progress is sent to the
workshops' own analytics service. This records which pages you
visited, which steps you did and what the checks found, and when. It
is used to find the places where the workshops are not clear, so they
can be improved. There is no account here, so nothing that is sent
says who you are. The code you type, the notebooks you make, the output
of your code and your answers to forms are never sent. Only which step
happened, and when.

## Trusting a workshop

When you open a workshop, JupyterLab shows what the workshop will do,
which is to write a notebook and run code in it, and asks how far you
trust it. Choose "Trust" to let the workshop's steps run as it
intends. "Restricted" asks you before each step that changes a file or
runs code. You are asked once for each workshop in this browser, and
again only if the workshop changes. The workshops are not trusted for
you automatically, because the code runs in your browser, on your
network, and that is your decision to make.
