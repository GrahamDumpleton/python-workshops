# Running a script

The thirty-first workshop of the course, and the fourth of the set
**From a Python notebook to a program**. The learner runs the file
`spending.py` of the spending tracker with `python spending.py` and
sees that it shows nothing, because a program shows only what it
prints. Then the learner writes the function `main`, and the function
`report_lines`, which returns the lines of a report, in three steps.
The last pages cover the name `__name__`, shown by running one small
file and then importing it, and the test `if __name__ == "__main__":`,
which the learner writes. Commands are run by click first, and then
typed by the learner.

Twenty-five minutes, in an editor and a terminal, with no notebook.
Python and its standard library only, nothing to install. It needs a
terminal, so it runs in JupyterLab only.

The directory `answers/` holds the file `spending.py` as it is after
each solution, and as it is for each wrong answer that an `attempt`
tries. The pages copy these files into the workspace with
`file-write` and `:from:`.
