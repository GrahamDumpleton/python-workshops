# Python in the terminal

The twenty-ninth workshop of the course, and the second of the set
**From a Python notebook to a program**. It is Python without the
notebook. The learner asks the terminal which Python it runs, with
`python --version` and `which python`, starts the interactive
interpreter, and types Python at the `>>>` prompt: expressions, names,
and a block at the `...` prompt. Then the up arrow, `exit()`, and the
limit that the next workshop answers: when the interpreter ends, every
name is gone, so code worth keeping belongs in a file. The Python is
all from the first workshops, so that the tool is the only new thing.
The first commands arrive by click, and the learner types the rest.

Twenty minutes, in a terminal. Python and its standard library only,
nothing to install. It needs a terminal that can run `python`, so it
runs in JupyterLab only.
