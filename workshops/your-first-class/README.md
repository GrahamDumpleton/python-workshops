# Your first class

The twenty-fourth workshop of the course, and the first of the set
**Your own types in Python**. It explains why a program needs types of
its own, with a purchase of the spending tracker that was a dictionary
until now. Then it covers `class`, making an object, the method
`__init__` and `self`, attributes and how to change one, a method
that returns a value, a method with a parameter, and a list of objects
with a loop that adds up their amounts. The class arrives by click.
The learner corrects a call that makes an object, makes an object and
changes it, writes two methods, and writes the loop.

Twenty-five minutes, in a notebook. Python and its standard library
only, nothing to install. It runs in JupyterLite as well as
JupyterLab.
