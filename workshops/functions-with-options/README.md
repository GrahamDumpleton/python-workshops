# Functions with options

The eleventh workshop of the course, and the second about functions.
It restates how a function is defined and called, then explains the
default value of a parameter, positional arguments and keyword
arguments, how a keyword argument changes one option of a function and
does not change the others, the docstring and `help()`, and a function
that calls another function. The learner changes or writes the code of
every step. It ends with two functions that the learner writes from
nothing, one of which calls the other.

Twenty-five minutes, in a notebook. Python and its standard library
only, nothing to install. It runs in JupyterLite as well as JupyterLab.
