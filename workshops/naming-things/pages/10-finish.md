# What you have learned

Your programs can now remember values, and you have written a small
program that was completely your own.

## The ideas

- A **name** refers to a value. Programmers also call a name that
  refers to a value a **variable**.

- An **assignment** gives a name to a value: `ticket_price = 12`. The
  name is on the left of the symbol `=`, and the value is on the
  right.

- Python calculates the right side of an assignment first. Then it
  makes the name refer to the result.

- Another assignment with the same name gives the name a new value:
  `steps = steps + 500`.

- A name is a label that is tied to a value. An assignment never
  connects two names to each other.

- A name must be assigned before it is used. A name that has no value
  gives a `NameError`.

- A good name uses whole words in small letters, joined with
  underscores, and says what the value means.

- `print()` shows a value from any line of a cell. A program outside
  a notebook shows only what it prints.

## The code

| Code | What it does |
|------|--------------|
| `tickets = 3` | makes the name `tickets` refer to the value `3` |
| `total = ticket_price * tickets` | calculates the right side, then gives the name `total` to the result |
| `steps = steps + 500` | gives the name `steps` a new value that uses its old value |
| `print(total)` | shows the value that the name `total` refers to |
| `print(apples, pears)` | shows two values on one line |
