# Naming things

The third workshop of the course, and the first that makes a program
remember a value. It explains why a program needs names, then
assignment, using names in calculations, giving a name a new value,
the picture of a name as a label on a value, what happens when a name
is used before it exists, how to choose good names, and `print()`. It
ends with a small program that the learner writes from nothing.

Twenty minutes, in a notebook. Python and its standard library only,
nothing to install. It runs in JupyterLite as well as JupyterLab.
