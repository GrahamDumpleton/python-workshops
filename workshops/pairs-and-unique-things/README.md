# Pairs and unique things

The thirteenth workshop of the course, and the fourth of **Python
functions and data**. It teaches two kinds of value that hold several
values. First the tuple: values that belong together, the index, why a
tuple cannot be changed, unpacking, and a function that returns more
than one value. Then the set: `set()` of a list removes duplicates, a
set has no order, `add`, `in`, and the operators `&` and `|`. The
learner writes most of the code, in five small tasks.

Twenty-five minutes, in a notebook. Python and its standard library
only, nothing to install. It runs in JupyterLite as well as
JupyterLab.
