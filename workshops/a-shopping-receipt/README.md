# A shopping receipt

The ninth workshop of the course, and the last of **Python first
steps**. The learner builds one program in six parts, with no code
given: from three lists that hold the items, quantities and prices of
a shopping trip, the program prints a receipt with one aligned line
for each item, a subtotal, a discount when the subtotal is over a
limit, and the total. One page first teaches the only new idea, a
width in an f-string. Each part has a check, two hints and a solution
that opens after the first try.

Twenty-five minutes, in a notebook. Python and its standard library
only, nothing to install. It runs in JupyterLite as well as
JupyterLab.
