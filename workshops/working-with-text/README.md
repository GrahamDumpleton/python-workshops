# Working with text

The fourth workshop of the course, and the first in which a value is
not a number. It explains what a string is and why Python treats text
differently from numbers, then quotes, joining strings with `+`,
f-strings (with a number shown to two decimal places), `len()`, the
index and the first slice, what a method is, and the methods `upper`,
`strip`, `replace` and `split`. It shows that a string never changes
and that a method gives back a new string. It ends with a line of
text that the learner builds from parts.

Twenty-five minutes, in a notebook. Python and its standard library
only, nothing to install. It runs in JupyterLite as well as
JupyterLab.
