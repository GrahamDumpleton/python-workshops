# Making decisions

The sixth workshop of the course, and the first in which a program
does different things for different values. It explains why a program
needs to choose, then booleans and comparisons, `if` with its indented
block, the difference between `=` and `==`, `else`, `elif`, and
combining conditions with `and`, `or` and `not`. It ends with a small
program with three branches that the learner writes from nothing.

Twenty-five minutes, in a notebook. Python and its standard library
only, nothing to install. It runs in JupyterLite as well as JupyterLab.
