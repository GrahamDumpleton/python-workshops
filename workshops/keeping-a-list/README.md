# Keeping a list

The seventh workshop of the course, and the first that keeps many
values under one name. It explains why a program needs lists, then
how to create one, how to get an item by its index from the start or
from the end and why counting starts at zero, slices, changing an
item, `append()`, `len()`, `in`, and `sorted()` against `.sort()`. It
ends with a small program that the learner writes from nothing.

Twenty-five minutes, in a notebook. Python and its standard library
only, nothing to install. It runs in JupyterLite as well as
JupyterLab.
