# Files, editors and terminals

The twenty-eighth workshop of the course, and the first of the set
**From a Python notebook to a program**. It is a second orientation,
because the place where the learner works changes here: there is no
notebook, and the work is done in the file browser, the editor and a
terminal. It says what is different from the site in the web browser
and why, and then covers the file browser and directories, the editor
and saving, the terminal with its shell, commands and prompt, the
current directory with `pwd` and `ls`, moving with `cd`, showing a file
with `cat`, stopping a program with Ctrl+C, and copying and pasting in
the terminal. There is no new Python. Commands go from a click that
runs the command, to a command that the page types and the learner
enters, to commands that the learner types.

Twenty-five minutes, in the editor and a terminal. Nothing to install.
It needs a terminal, so it runs in JupyterLab only, on Linux and
macOS.
