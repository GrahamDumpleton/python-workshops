# CSV and JSON

The twenty-first workshop of the course, and the fourth of the set
**Working with real data in Python**. It explains what a CSV file is,
and shows on a field that holds a comma why `.split(",")` is not
enough. Then it reads CSV files with `csv.reader` and
`csv.DictReader`, where every value is a string, and writes one with
`csv.writer` and `newline=""`. It explains what JSON is and when each
format is used, reads the monthly budgets with `json.load()`, and
saves changed budgets in a new file with `json.dump()` and `indent=2`.
The learner corrects one cell and writes five, and the data files are
shown under the notebook.

Twenty-five minutes, in a notebook. Python and its standard library
only, nothing to install. It runs in JupyterLite as well as
JupyterLab.
