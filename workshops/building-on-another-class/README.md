# Building on another class

The twenty-sixth workshop of the course, and the third of the set
**Your own types in Python**. It restates what a class is, then
teaches inheritance: a child class that has the attributes and the
methods of its parent class, adding a method, replacing a method,
`super().__init__(...)` for a child class with an attribute of its
own, and `isinstance()`. It then teaches composition, an object that
holds other objects as attributes, and a plain rule for choosing
between the two. The learner writes a method of a child class,
repairs a child class that forgot to call the `__init__` of its
parent, writes a function that uses `isinstance()`, and writes a
method of a class that holds other objects.

Twenty-five minutes, in a notebook. Python and its standard library
only, nothing to install. It runs in JupyterLite as well as
JupyterLab.
