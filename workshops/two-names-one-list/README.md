# Two names, one list

The sixteenth workshop of the course, and the seventh of the set
**Python functions and data**. It explains why a change to a list can
appear under another name, and has the learner meet each mistake on
purpose: two names for one list, `is` against `==`, a real copy with
`.copy()`, mutable and immutable values, a function that changes its
argument, a copy of a list of lists that still shares the inner lists,
and local against global names. Each surprise is predicted first, then
shown, then explained, and then the learner corrects the code.

Twenty-five minutes, in a notebook. Python and its standard library
only, nothing to install. It runs in JupyterLite as well as JupyterLab.
