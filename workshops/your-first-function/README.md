# Your first function

The tenth workshop of the course, and the first of the set **Python
functions and data**. It explains why a program needs functions, then
how to define a function with `def` and call it, parameters and
arguments, functions with two parameters, `return` and the return
value, the difference between `return` and `print()` on a page of its
own, and `None`, the value that a function with no `return` gives. The
learner writes five functions, and the last one is written from a
short description alone.

Twenty-five minutes, in a notebook. Python and its standard library
only, nothing to install. It runs in JupyterLite as well as
JupyterLab.
