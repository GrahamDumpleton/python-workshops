# What you have learned

You have written your first Python, and one expression that was
completely your own.

## The ideas

- A **program** is a list of instructions. The computer follows them
  exactly, in order.

- **Python** is the language that you write, and the **interpreter**
  is the program that reads your code and performs it.

- An **expression** is a piece of code that Python calculates to
  produce a **value**.

- An **integer** is a whole number. A **float** is a number with a
  decimal point. A float is not always exact.

- A notebook shows only the value of the last line of a cell. This is
  a rule of the notebook, not of the Python language.

- A **comment** begins with `#`. Python ignores it.

## The operators

| Operator | What it does | Example | Value |
|----------|--------------|---------|-------|
| `+` | adds | `2 + 3` | `5` |
| `-` | subtracts | `9 - 2` | `7` |
| `*` | multiplies | `6 * 5` | `30` |
| `/` | divides, and always gives a float | `7 / 2` | `3.5` |
| `//` | divides, and keeps the whole part | `17 // 5` | `3` |
| `%` | divides, and gives the remainder | `17 % 5` | `2` |

Python multiplies and divides before it adds and subtracts.
Parentheses `( )` change the order: the part inside them is calculated
first.

## What comes next

In this workshop, Python calculated each value, showed it, and then
