# Talking to Python

The first workshop that teaches Python. It starts before any code, with
what a program is and what the Python interpreter does. Then it uses
Python as a calculator: the operators, whole numbers and decimal
numbers, which part of a calculation is done first, whole number
division and remainders, and why `0.1 + 0.2` is not exactly `0.3`. It
ends with the first calculation that the learner writes from nothing.

Twenty minutes, in a notebook. Python and its standard library only,
nothing to install. It runs in JupyterLite as well as JupyterLab.
