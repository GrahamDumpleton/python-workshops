# Reading and writing files

The eighteenth workshop of the course, and the first of the set
**Working with real data in Python**. It explains what a file is and
why a program reads and writes files, then `open()` and the `with`
block, `read()`, a `for` loop over the lines of a file, the newline
character and `strip()`, `float()` and `int()` to turn text into
numbers, writing with the mode `"w"`, adding with the mode `"a"`, and
`Path` from `pathlib` with `exists()`, `read_text()` and
`write_text()`. The spending data of the running project, the file
`spending.csv`, is shown under the notebook before any code reads it.
Each idea is shown with one cell, and the learner then writes a cell
of their own: six cells in all.

Twenty-five minutes, in a notebook with a file shown under it. Python
and its standard library only, nothing to install. It runs in
JupyterLite as well as JupyterLab.
