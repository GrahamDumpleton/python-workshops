# The batteries included

The twentieth workshop of the course, and the third of the set
**Working with real data in Python**. It explains what a module is,
what the standard library is and what `import` does, with `import
math` and `from math import sqrt`. Then it shows four modules: `math`
(`floor`, `ceil` and `pi`), `random` (always with a seed: `randint`,
`choice` and `shuffle`), `datetime` (the type `date`, the days between
two dates and `strftime()`) and `collections` (`Counter` and
`most_common()`). The examples use the spending of Mariam, the person
that this set of workshops follows. On the last page of work the
learner reads the documentation of a module that the workshop has not
shown, and finds the function that the task needs. The learner writes
code in eight steps, and five of them are functions.

Twenty-five minutes, in a notebook. Python and its standard library
only, nothing to install. It runs in JupyterLite as well as
JupyterLab.
