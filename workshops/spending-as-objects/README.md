# Spending as objects

The twenty-seventh workshop of the course, and the last of the set
**Your own types in Python**. The learner builds one program in seven
parts, with no code given for the new work: a dataclass `Purchase` with
a method `month()`, a class `Ledger` that holds a list of purchases, a
function that reads the clean CSV file of three months of purchases
into a ledger, and methods of the ledger that give the total, the
total for each category and for each month, the largest purchase, the
categories that went over their budget in a month, and the lines of a
report, which the learner's code writes to a text file. Each part has
a check, hints and a solution that opens after the first try. From
part 4 on, the cell of each part arrives with the class as it is
then, so a learner who skipped a part can continue.

Twenty-five minutes, in a notebook, with the data file and the report
shown under it. Python and its standard library only, nothing to
install. It runs in JupyterLite as well as JupyterLab.
