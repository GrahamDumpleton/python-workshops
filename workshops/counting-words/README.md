# Counting words

The seventeenth workshop of the course, and the last of **Python
functions and data**. The learner builds one program in six parts,
with no code given: from the text of five of Aesop's fables, the
program makes a list of clean words, counts the words into a
dictionary, counts the words of all the fables together, and finds the
most common words, the longest fable and the words that are in every
fable. Each part has a check, two hints and a solution that opens
after the first try. The text of the fables is from the translation by
George Fyler Townsend, which is in the public domain.

Twenty-five minutes, in a notebook. Python and its standard library
only, nothing to install. It runs in JupyterLite as well as
JupyterLab.
