# Looping over anything

The fourteenth workshop of the course. It shows that the `for` loop
works with more than lists: over a string it gives the characters, and
over a dictionary it gives the keys. It then teaches `.values()`,
`.items()` with unpacking, `enumerate()` to number the passes of a
loop, and `zip()` to use two lists together, in place of the index
loop of **Doing it again**. It ends with a function that the learner
writes from nothing, which uses a loop over the items of a dictionary.

Twenty-five minutes, in a notebook. Python and its standard library
only, nothing to install. It runs in JupyterLite as well as JupyterLab.
