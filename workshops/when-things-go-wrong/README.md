# When things go wrong

The fifth workshop of the course, and the one that teaches the learner
to read an error message. It explains that errors are normal, then the
three parts of an error message: the type of the error, the line and
the message. Every cell in the workshop has a mistake in it, and the
learner runs it, reads the message and corrects the mistake. The
errors are `NameError`, `TypeError`, `IndexError`, `SyntaxError` and
`IndentationError`. It ends with a cell that has three different
errors, which the learner corrects one at a time.

Twenty-five minutes, in a notebook. Python and its standard library
only, nothing to install. It runs in JupyterLite as well as JupyterLab.
