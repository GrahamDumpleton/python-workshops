# Doing it again

The eighth workshop of the course, and the first that makes a program
repeat work. It explains why a program needs to repeat, then the `for`
loop over a list and over `range()`, adding up a total, counting the
items that pass a test, finding the largest value, and one index used
with two lists. It then shows the `while` loop, and why its condition
must be able to become false, with a loop that carries a safety limit.
It ends with a program that the learner writes from nothing: one loop
that produces a total, a count and the largest value.

Twenty-five minutes, in a notebook. Python and its standard library
only, nothing to install. It runs in JupyterLite as well as JupyterLab.
