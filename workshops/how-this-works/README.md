# How these workshops work

The first workshop of the course, and the place to start. It teaches
how to use the workshops, not Python: reading a page, clicking an
action, running a cell in a notebook, why the course starts in a notebook and
where it goes afterwards, changing code yourself, and how
checks, hints and questions help. It uses a few lines of Python as
material and explains none of them yet.

Fifteen minutes, in a notebook. Python and its standard library only,
nothing to install. It runs in JupyterLite as well as JupyterLab.
