# What comes next

You have finished the first workshop. You now know how to:

- read a page, and move between pages with `Next` and `Previous`

- click an action, and see its result in the notebook

- run a cell yourself, with `Shift` and `Enter`

- read a check, and use its message when it fails

- change code in a cell, and run it again

- open a hint, and ask for a solution when you need one

- answer a question

## How the course works

Every workshop in this course has the same parts that you used here.
What changes is how much you do yourself.

In the first workshops, actions add most of the code for you. You
watch what the code does, predict results, and make small changes.

Then, step by step, the workshops ask you to type more of the code
yourself. First you change code that is almost right. Then you write a
few lines of your own. At the end of the course, you write a complete
program, and the workshop only checks your work.

This is deliberate. Actions save your time on the parts that are not
the lesson. Typing code yourself is how you learn to program. If a
task feels difficult, that is normal, and the hints are always there.

## Finish the workshop

This is the last page, so the button at the bottom of the panel is
`Finish`, not `Next`. Click `Finish` now.

A window opens that says the workshop is complete, and offers you the
next workshop, **Talking to Python**. In that workshop you learn what
a program is, and you write your first Python calculations.
