# Where the money went

The twenty-third workshop of the course, and the last of the set
**Working with real data in Python**. The learner builds one program in
six parts, with no code given: from an untidy CSV file of three months
of purchases and a JSON file of budgets, the program reads the
purchases and skips the rows that cannot be read, adds up the total for
each category and for each month, finds the largest purchase, finds the
categories that went over their budget in a month, and writes a report
to a text file. Each part has a check, hints and a solution that opens
after the first try. The function that cleans one row is given, since
the workshop before this one builds it.

Twenty-five minutes, in a notebook, with the data file and the report
shown under it. Python and its standard library only, nothing to
install. It runs in JupyterLite as well as JupyterLab.
