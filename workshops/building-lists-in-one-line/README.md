# Building lists in one line

The fifteenth workshop of the course, and the one that teaches
comprehensions. It starts from the loop that builds a new list with an
empty list and `.append()`, then writes the same work as a list
comprehension, with every comprehension shown beside the loop that it
replaces. It covers the expression at the start of a comprehension, a
condition that keeps only some items, both together, and the
dictionary comprehension. It ends with a page on when a loop is
clearer, where the learner writes a comprehension again as a loop.

Twenty-five minutes, in a notebook. Python and its standard library
only, nothing to install. It runs in JupyterLite as well as JupyterLab.
