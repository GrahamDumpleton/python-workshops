# Looking things up

The twelfth workshop of the course, and the third of the set about
functions and data. It explains why a program looks values up by a
name instead of a position, then dictionaries: keys and values, lookup
with square brackets, the `KeyError` that a missing key gives, `get()`
with and without a default, adding and changing values, testing for a
key with `in`, `len()`, and the pattern that counts things with a
dictionary. It ends with a function that the learner writes, which
uses a dictionary of prices to calculate the cost of a basket.

Twenty-five minutes, in a notebook. Python and its standard library
only, nothing to install. It runs in JupyterLite as well as
JupyterLab.
